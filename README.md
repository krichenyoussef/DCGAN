# DCGAN — Deep Convolutional Generative Adversarial Network

This project implements a Deep Convolutional GAN (DCGAN) to generate realistic images from random noise using an unsupervised learning approach.
DCGANs improve classical GANs by using convolutional / transposed-convolutional layers, enabling more stable training and high-quality image generation.

🚀 Overview

A DCGAN is composed of two adversarial neural networks:

🔹 Generator

Takes a latent noise vector as input

Uses transposed convolutions, batch normalization, and ReLU

Learns to produce realistic images matching the target dataset

🔹 Discriminator

A CNN-based binary classifier

Uses strided convolutions and LeakyReLU

Learns to distinguish between real images and fake ones generated by the Generator

Both networks train together in a minimax game where the Generator continuously improves to fool the Discriminator.
